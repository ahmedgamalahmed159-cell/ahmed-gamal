# Ahmed Gamal | Portfolio

Personal portfolio of Ahmed Gamal (Arabic educational content, design work, and a live learning platform), built with React + Vite + Tailwind.

- Live: deployed via Vercel
- Real projects only: atallm.vercel.app (Et3alem learning platform), YouTube @Et3alem-i4v, a listed children's book, and labeled demo widgets.
- Demo projects are labeled as demos. No fabricated metrics.

## Run locally
```
npm install
npm run dev
```
